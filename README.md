# Asset backup

Copies of media the main README loads from GitHub `user-attachments` URLs, which GitHub does not document as stable. If an attachment stops loading, point the README here.

| File | What | Source |
| --- | --- | --- |
| `readme/hero.mp4` | README hero video, 41 s, 1160x580, 30 fps | https://github.com/user-attachments/assets/31bf24c7-7fe7-43d0-92d7-a4a3bd6d4c11 (#1188), byte-identical |
| `readme/hero.webp` | The same cut as a looping animated WebP, 960 px, 10 fps | `scripts/scenarios/hero-gif.sh --crop 0:0:1160:580 --webp hero.mp4 0 42` |

Raw URLs: `https://github.com/omesser/fidget/raw/assets-backup/readme/hero.mp4` and `.../readme/hero.webp`.
