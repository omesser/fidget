Bubble Ceiling Invert

Dated design · #546 · 2026-09-09

When the Speech bubble would clamp to the ceiling and cover the Character's face (#441 behavior, left), invert the bubble below the Character at the same mirrored distance (10px gap, right).

Decision

The #441 clamp-and-overlap (left) is readable over wallpaper, but the speaker disappears. The #546 invert (right) keeps the Character visible. The 10px gap above becomes a 10px gap below.

This is a ceiling/cover case only — not a return of the general below-head flip retired in #456. The bubble inverts only when placing it above would cause it to clamp and cover the face.

Acceptance

  • Character remains recognizable while the Speech bubble is visible ✓
  • Bubble never leaves the display ✓
  • Vertical gap mirrors the normal above gap ✓
  • Readability bar from #456 still passes ✓
